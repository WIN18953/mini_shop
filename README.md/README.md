# รายงานโครงงาน MiniShop  
## ระบบร้านค้าออนไลน์ด้วย Flask และ SQLite

---

## 1. บทนำ

โครงงาน MiniShop เป็นระบบร้านค้าออนไลน์ขนาดเล็ก (Mini E-Commerce Web Application) 
พัฒนาด้วยภาษา Python โดยใช้ Flask Framework และฐานข้อมูล SQLite 
เพื่อศึกษาและฝึกปฏิบัติการพัฒนาเว็บแอปพลิเคชันแบบ Full Stack เบื้องต้น

ระบบนี้ถูกออกแบบให้สามารถจัดการสินค้า การเพิ่มสินค้าใส่ตะกร้า 
การสั่งซื้อสินค้า (Checkout) และการแสดงผลคำสั่งซื้อสำหรับผู้ดูแลระบบ (Admin)

---

## 2. วัตถุประสงค์

1. เพื่อศึกษาการพัฒนา Web Application ด้วย Flask
2. เพื่อเรียนรู้การเชื่อมต่อและจัดการฐานข้อมูลด้วย Flask-SQLAlchemy
3. เพื่อเข้าใจการทำงานของ Session ในการจัดเก็บข้อมูลตะกร้าสินค้า
4. เพื่อออกแบบระบบสั่งซื้อสินค้าและบันทึกข้อมูลลงฐานข้อมูล

---

## 3. ขอบเขตของระบบ

### 3.1 ฝั่งผู้ใช้งาน (User)
- แสดงรายการสินค้า
- เพิ่มสินค้าใส่ตะกร้า (Add to Cart)
- ทำรายการสั่งซื้อ (Checkout)

### 3.2 ฝั่งผู้ดูแลระบบ (Admin)
- แสดงรายการคำสั่งซื้อทั้งหมด
- คำนวณยอดรวมรายได้จากการขาย

---

## 4. เทคโนโลยีที่ใช้

- ภาษา Python 3
- Flask Framework
- Flask-SQLAlchemy
- SQLite Database
- HTML / CSS
- Jinja2 Template Engine

---

## 5. โครงสร้างระบบ

```

mini_shop/
│── app.py
│── models.py
│── templates/
│   ├── home.html
│   ├── admin.html
│── static/
│── instance/
│   └── minishop.db

```

---

## 6. โครงสร้างฐานข้อมูล

### 6.1 ตาราง Product
- id (Primary Key)
- name (ชื่อสินค้า)
- price (ราคาสินค้า)

### 6.2 ตาราง Order
- id (Primary Key)
- product_name (ชื่อสินค้า)
- price (ราคา)
- (อาจเพิ่มเติม status ในอนาคต)

---

## 7. หลักการทำงานของระบบ

1. ผู้ใช้เข้าสู่หน้าแรกเพื่อดูรายการสินค้า
2. เมื่อกดเพิ่มสินค้า ระบบจะบันทึก id ของสินค้าไว้ใน Session
3. เมื่อกด Checkout ระบบจะ:
   - ดึงข้อมูลสินค้าในตะกร้า
   - บันทึกข้อมูลลงในตาราง Order
   - ล้างข้อมูลใน Session
4. ผู้ดูแลระบบสามารถเข้าหน้า Admin เพื่อดูรายการคำสั่งซื้อทั้งหมด
   และระบบจะคำนวณยอดรวมรายได้โดยอัตโนมัติ

## 8. วิธีการติดตั้งและใช้งาน

```

```
